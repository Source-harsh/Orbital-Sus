# Orbital-Sus
AI-assisted cyber-physical defence system for simulated spacecraft — detects anomalies, identifies cyber threats, and demonstrates automated containment and recovery.
# Orbital Sus - Simulation Module

The simulation module provides a controlled cyber-physical spacecraft environment for Orbital Sus.

It simulates:

- Normal spacecraft behaviour
- Hardware faults
- Environmental disturbances
- Cyber-induced anomalies
- Threat correlation
- Automated containment
- Safe mode
- Trusted monitoring
- Recovery
- Event replay
